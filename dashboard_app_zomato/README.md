# Zomato Streamlit Dashboard

This folder contains the Streamlit dashboard app for the Zomato sentiment analysis project.

## Data source
- `../dashboard_zomato/data/`

## Main app
- `app.py`

## Dependencies
- `streamlit`
- `plotly`
- `pandas`

## Run
```powershell
.venv\Scripts\python.exe -m streamlit run dashboard_app_zomato\app.py
```
