# MBA Project

This repository contains the source code, dashboards, and analysis scripts for the Zomato and Swiggy review analysis project.

## Included in this repository

- Python data collection and dataset-building scripts
- Analysis code under `analysis_zomato_full/`
- Dashboard apps under `dashboard_app_zomato/`, `dashboard_zomato/`, and `dashboard_brand_comparison/`
- Project documentation under `documentation/`

## Excluded from version control

Large generated datasets, exported archives, local virtual environments, `node_modules`, and secrets in `.env` are intentionally ignored so the repository stays lightweight and safe to publish.

## Getting started

1. Create and activate a Python virtual environment.
2. Install Python dependencies from the requirements files in the repo as needed.
3. Install Node dependencies with `npm install` if you need the JavaScript tooling.
4. Run the relevant analysis script or dashboard app for the part of the project you want to work on.
