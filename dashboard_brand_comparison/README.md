# Brand Comparison Dashboard Data

This folder contains dashboard-ready comparison tables for Zomato vs Swiggy.

## Comparison basis
- Google Play only
- Uses the final sentiment-ready datasets for both brands
- Uses `sentiment_label` from the final datasets for a fair apples-to-apples brand comparison
