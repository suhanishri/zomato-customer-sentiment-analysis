\textbf{Title of Instrument:} Customer Perception of Zomato App Reviews and Service Experience

\textbf{Purpose:} This questionnaire is designed to capture customer perceptions of Zomato with respect to service experience, app usability, pricing, refunds, customer support, trust, and overall brand preference.

\textbf{Instruction to Respondents:} Please read each question carefully and choose the option that best reflects your experience. The information collected is intended purely for academic purposes.

\section*{Project Repository and Supporting Files}

To support transparency and reproducibility, the codebase developed for this project has been maintained in a version-controlled GitHub repository:

\url{https://github.com/suhanishri/zomato-customer-sentiment-analysis/tree/main}

The repository contains the major implementation components used in the study, including:

\begin{enumerate}[label=\arabic*.]
    \item Google Play review collection and cleaning scripts
    \item final dataset construction workflows for Zomato and Swiggy
    \item sentiment modeling and benchmark comparison scripts
    \item theme analysis outputs and dashboard-ready summary tables
    \item Streamlit dashboard application files
    \item presentation and research documentation assets
\end{enumerate}

This repository serves as a supporting annexure source for the technical implementation of the study and may be referred to for understanding the data pipeline, modeling workflow, and dashboard development process.
